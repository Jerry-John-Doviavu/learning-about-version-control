Author: Jerry John Doviavu

Solving merge conflicts takes conscious effort, but I can do it!

## My Opinions on Version Control

### What I like most

I like that it lets me see exactly what changed, when, and why, which makes collaborating on a project much clearer.

### What I find challenging

I find the number of commands, such as branch, merge, rebase and reset, hard to remember, and I am not always sure which one to use.
